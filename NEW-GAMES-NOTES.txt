separate copies of the whole site (same for www/). Firebase Hosting
serves index.html at your root URL (https://pixelarcade.web.app/), while

didn't have, plus a couple of other small improvements (a shared
onlineErrorMessage() helper for clearer connection-error text, and some

their www/ copies) now have the exact same game logic and online

Going forward: if you edit game logic by hand, remember to make the same

ONLINE MULTIPLAYER UPDATE
--------------------------------------------------------------------
Connect Four and Checkers now have a real "Online" mode, wired up the
exact same way as Tic-Tac-Toe (Create Room / Join Room / 5-letter code,
via the shared OnlineRoom Firestore engine already in arcade.html — pure
client-side Firestore reads/writes, no Cloud Functions, so this stays
100% on the Firebase Spark (free) plan, same as everything else here).
So now 4 of the 16 games have real online multiplayer: Tic-Tac-Toe,
Connect Four, Checkers, Dots & Boxes.

Reversi and Battleship are still local (2P hot-seat) + Vs Computer only.
The pattern to wire them up next is the same one used for Connect
Four/Checkers:
  - Flatten the board to a 1D array in the room's `state` (Firestore
    doesn't support arrays-of-arrays directly, hence e.g. Connect Four's
    6x7 board is stored as a flat 42-element array, Checkers' 8x8 as 64).
  - OnlineRoom.create(gameName, initialState) / OnlineRoom.join(code, gameName)
  - OnlineRoom.move(patchFn) to submit a move as a Firestore transaction
    (patchFn validates the move against `state` and returns the new state,
    or null to reject it).
  - OnlineRoom.onUpdate(callback) to re-render whenever the room doc changes.
  Search for "c4OnlineDropCol"/"c4OnRoomUpdate" (Connect Four) or
  "ckOnlineMove"/"ckOnRoomUpdate" (Checkers) in arcade.html as the
  reference implementations — Reversi would follow the Connect Four shape
  (simple flat-array patch). Battleship takes more work since it needs two
  separate per-player boards (each player's ship layout + the other
  player's shot history) inside one room doc instead of one shared board.
