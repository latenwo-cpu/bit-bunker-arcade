HOW TO APPLY
1. Copy the "public" and "www" folders from this zip over the ones in your project (overwrite).
2. (Done) The contact email is already set to pheonixadvertising1@gmail.com.
3. Run: firebase deploy --only hosting
4. In admin.html, make sure remote ad config / game-end interstitials stay OFF until AdSense approves the site.
5. Open the live site, check every game page and the About/Contact/Terms pages, then request a new AdSense review.
