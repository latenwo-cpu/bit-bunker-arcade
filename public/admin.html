Ad Configuration

Choose how ads render across the arcade. This is read live by arcade.html — changes apply immediately for new page loads.

AdSense
AdMob

AdMob only renders inside a native app shell (e.g. this page wrapped with Capacitor/Cordova) that exposes window.AdMobBridge.showBanner(unitId, slot). In a plain browser tab it shows a text placeholder instead.

AdMob Interstitials (app only)

Full-screen AdMob ads after a win, a loss, long play, or hub return. Create Interstitial units in AdMob and paste the IDs here. Saved with the main Save button.

Manual Ads

Pick a slot, then upload an image file (stored free, directly in your database — no hosting needed) or paste an image URL, plus a click-through link. Or use raw HTML.
