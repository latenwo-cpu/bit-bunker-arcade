NEW GAME ADDED: BUNKER DEFENSE (22 games total now)
------------------------------------------------------
A 3D tower-defense game built in the same Three.js engine as Neon Runner
3D / Turbo Drift 3D / Neon Blaster 3D. Low-poly enemies spawn around the
edge of a circular arena and march toward your bunker's core hatch at
the center. You control a turret mounted on the hatch: move the mouse
(or drag a finger) to aim, hold the mouse button (or touch) down to
auto-fire a stream of energy bolts. Score points and survive as many
waves as you can — each wave sends more enemies, a little faster, with
tougher types mixed in the longer you last.

ENEMY TYPES
-----------
- Grunt (magenta): 1 hit to kill, baseline speed. The bulk of every wave.
- Runner (amber): fast, but dies in 1 hit. Starts appearing from wave 2.
- Brute (violet): takes 3 hits, moves slowly, deals double core damage
  if it reaches the hatch. Starts appearing from wave 3, chance rises
  slowly with each wave (capped).

CORE / SCORING
---------------
- The bunker core starts with 10 HP. A grunt or runner reaching the
  center costs 1 HP; a brute costs 2. Game over at 0 HP.
- Points: Grunt 10, Runner 15, Brute 30, plus a wave-clear bonus
  (wave number x 20) awarded the moment the last enemy in a wave dies.
- Best wave reached is saved to localStorage ('bunkerBestWave') and
  shown on the briefing screen; score is reported via
  logEvent('game_end', {game:'bunkerdefense', mode:'solo', score}) the
  same way every other scoring game reports to the Player Profile's
  high-score table, coins, and XP.

WHERE IT LIVES / HOW IT'S WIRED IN
------------------------------------
Fully self-contained, single-player only — no "vs computer" or online
mode, same reasoning as Simon Says (a single shared arena doesn't have
an obvious competitive shape without a bigger redesign). It plugs into
every existing arcade-wide system with zero special-casing:
  - New cabinet button on the hub grid (🛡️ Bunker Defense), styled
    "cabinet-3d" like the other three 3D games
  - New GAME_META entry ('bunkerdefense') so it shows up in
    Favorites/Recents, the Explorer/Arcade Legend achievements, and the
    daily-challenge rotation automatically
  - Reuses the shared 3D helpers already in the file (make3DRenderer,
    fit3DCanvas) and the existing .g3d-garage / .g3d-stage / .g3d-hud /
    .g3d-overlay / .g3d-reticle / .g3d-wavebanner CSS — no new CSS
    needed. (.g3d-wavebanner existed in the CSS already, defined but
    unused until now — Bunker Defense is the first game to actually use
    it, for "WAVE n" / "WAVE n CLEARED" banners.)
  - Follows the same stop3D convention as the other 3D games (set on
    start, cleared on backToGarage) so navigating away mid-round always
    cleans up the renderer/animation loop correctly.
  - The bunker/hatch centerpiece deliberately echoes the arcade's own
    logo (ring + rivets around a central hatch) as a nod to the "Bit
    Bunker" origins mentioned in your icon file.

FIX (this update)
------------------
The very first version of this file shipped with a bug: the CSS rule
that gives the 3D canvases their size (#runner-canvas, #drift-canvas,
#shooter-canvas{ width:100%; aspect-ratio:16/10; ... }) never had
#bunker-canvas added to it. That meant the Bunker Defense <canvas> had
no real width/height, so nothing ever rendered — but the game loop
itself (waves, enemy movement, core damage, scoring) was still running
invisibly underneath, which is why you'd see the score and wave number
ticking up on a blank/background-colored screen with enemies silently
draining the core. Added #bunker-canvas to both the base sizing rule
and its mobile aspect-ratio override — the arena, turret, and enemies
now actually render.
