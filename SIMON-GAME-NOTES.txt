NEW GAME ADDED: SIMON SAYS (21 games total now)
--------------------------------------------------
A classic 4-color memory sequence game: the board flashes a growing
pattern (green/red/yellow/blue), you repeat it back by tapping the
same pad. Each round adds one more step and the playback speeds up
slightly (capped so it never gets unfair). One wrong tap ends the run.

WHERE IT LIVES
--------------
Fully self-contained, single-player, no "vs computer" or online mode
(a turn-based memory game doesn't have an obvious 1v1 shape, same
reasoning as Snake/2048/Minesweeper's solo-only pieces). It plugs into
all the existing arcade-wide systems with zero special-casing:
  - New cabinet button on the hub grid (🎵 Simon Says)
  - New GAME_META entry ('simon') so it shows up in Favorites/Recents,
    the Explorer/Arcade Legend achievements, and the daily-challenge
    rotation automatically
  - Best score (rounds survived) is saved to localStorage
    ('simonBest') and also reported via logEvent('game_end', {game:
    'simon', score}) so it appears on the Player Profile's high-score
    table the same way every other scoring game does
  - Uses the existing Engagement sound toggle (reads the same
    arcade_profile_v1.soundOn flag) so muting sound in the header
    mutes Simon's tones too
